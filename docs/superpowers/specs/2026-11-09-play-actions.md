# PetWorld Play 배포

사용자가 승인한 기존 앱의 배포 방식을 `com.haebi.petworld`에 적용합니다. 현재 main의 기능과 아이콘을 유지하며 Draft #5의 기능은 포함하지 않습니다.

- 기존 `Android CI`의 정확한 main 커밋 검증이 성공하면 내부 테스트에 자동 배포합니다.
- 수동 check/build/initialize/deploy와, 명시적으로 요청한 기존 internal 코드의 alpha 승격을 지원합니다. 프로덕션은 허용하지 않습니다.
- 최초 버전은 `0.1.0 (1)`이며 빈 Play inventory에만 internal draft를 등록합니다. 일반 배포는 모든 등록 버전보다 큰 코드를 사용합니다.
- 앱 전용 업로드 인증서를 고정하고 main 전용 google-play 환경에서만 서명·WIF 단기 인증을 사용합니다. 누락된 키를 임의 생성하거나 다른 앱 키로 대체하지 않습니다.
- AAB/APK의 패키지·버전·서명과 실제 포함 ELF 및 APK ZIP의 16KB 정렬을 확인합니다. 네이티브가 없는 AAB/APK 쌍은 0개라는 사실을 기록합니다.
- API 커밋 후 새 편집에서 트랙과 업로드 해시를 확인합니다. Console 게시와 실제 설치는 별도로 확인합니다.
- 개인정보처리방침은 현재 main의 로컬 기능만 설명합니다. 앱 기능·화면·의존성은 배포에 필요한 범위 이외에 변경하지 않습니다.
