# FB-05-D — 동기화 상태 및 충돌 검토 UI

- 선행 Draft PR #61 수정 HEAD a6e298f043e2e4b9a9e7806fc4277fbea2980dd2. 계정 화면에 FirebaseDev signed-in 전용 동기화 카드와 검토 목록을 추가한다. 기존 Guest UI/디자인 컴포넌트 유지.
- 계정별 Room 집계·미확정/재시도/차단/전송 확인 건수 및 마지막 저장 스캔 상태를 표시. 20개씩 최대 500개 검토 항목. 미전송·불명확·보류 상태를 완료로 표시하지 않는다.
- 검토 다이얼로그는 로컬/서버 스냅샷의 표시용 필드를 비교하며 NULL과 0을 구별한다. 원문 UID/계정 키/작업 지문은 표시하지 않는다. 현재 기록 유지 버튼은 비교 종료일 뿐 충돌을 해결/폐기하지 않는다.
- 서버 기록 적용 및 다시 시도 버튼은 현재 검증 세션 lease·실제 Google 계정 일치·복원 상태를 확인한 경우만 활성화. 서버값 적용은 기존 C2의 fresh server digest/revision/local snapshot/CAS 검증을 호출. 미전송 이력 보존 및 시도된 전송 폐기 금지 유지.
- 계정 변경 시 UI state를 계정별로 재생성. signed-in 프로필 Room invalidation 관찰을 추가해 원격 반영 후 기존 화면을 새로 고친다.
- 실제 앱에서 lease activate 호출은 여전히 없음. 따라서 실제 사용 중에는 기본적으로 조회/비교만 가능하며 서버값 적용과 다시 시도는 비활성. 검증된 사용자 동의·기준선 활성화, keep-local 재기준화, 삭제/사진 승인 및 실제 마지막 성공 시각 저장은 후속. 자동 동기화 완료라고 판단하지 않는다.
- 테스트: 계정별 상태 집계/페이지 제한, NULL·0 표시, 승인 가능 조건, 프로필 변경 Flow 갱신. 기존 guest UI smoke 유지. 로그인 계정의 실제 화면·실서버·WorkManager 실기기 검증은 별도 필요.
- DB schema, Firebase Rules, 실제 서버 데이터 및 Google Play 변경 없음. 선행 #55~61와 함께 Draft 보존.
