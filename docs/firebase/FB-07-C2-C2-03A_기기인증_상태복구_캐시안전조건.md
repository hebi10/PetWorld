- 기기 인증 복구: 현재 로그인 계정의 명시적 삭제 승인·최근 재인증·검증된 readiness 이후 해당 계정과 job에만 단일 복구 슬롯을 예약한다. 예약 후 기존 암호화 요청 journal을 저장하고 실제 전송 직전에 계정/차단 상태를 다시 검사한다. 다른 계정의 슬롯 덮어쓰기, 인증 거부 시 새 journal 생성, 계정 목록 탐색 금지. 슬롯은 Android Keystore AES-GCM, 기기 인증 유효 시간 30초 및 noBackup AtomicFile로 보호하며 ticket/UID/email을 복사하지 않는다. Android 30+ 기기 credential 전용, API26~29 기존 인증 유효 시간 설정 사용; 실제 기기 credential Activity 결과도 반드시 요구한다. 실제 PIN/패턴/암호·Keystore 지원 여부와 재시작 복구는 기기 검증 필요.
