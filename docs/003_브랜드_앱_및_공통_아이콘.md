# PetWorld 1-B — 브랜드·앱 아이콘 및 공통 기능 아이콘

## 작업 범위
- 브랜드 심볼: 강아지와 고양이를 함께 표현한 검정·흰색 단색 마크. 원본은 이미지 생성 도구의 브랜딩 시안에서 추출하고 투명 배경과 단색 대비로 정리.
- 앱 아이콘: Android 밀도별 레거시 PNG, Adaptive Icon(108dp 레이어), Android 13+ 테마 아이콘(monochrome)으로 연결.
- 브랜드 워드마크: 원본 아트워크는 심볼만 유지하며 'PetWorld' 텍스트는 Android 기본 서체를 활용해 출력. 라이선스 불명 외부 서체를 포함하지 않음.
- 공통 아이콘: Material Outlined 단색 어휘를 `PetIcons.kt`에서 한 번에 지정하고 `PetIcon` 래퍼는 24dp 색·크기 규칙을 담당.
- 기능 구현은 기존 1-A 범위를 유지. 프로필·식사·음수·배변·체중 CRUD와 가계부·복약 등은 본 단계에서 활성화하지 않음.

## 브랜드 원칙
- 콘셉트: Pet Journal Mono / 반려동물의 일상과 건강을 기록하는 차분한 도구.
- 컬러: 1-A 팔레트 유지(라이트 #FFFFFF 배경·#191919 표시, 다크 #101010 배경·#F2F2F2 표시).
- 비권장: 베이지·크림 색 강조, 입체감, 그라데이션, 과장된 둥근 타일, 그림자, 새로운 유료 폰트/라이브러리 도입.
- 심볼: 독립적으로 의미가 전달되는 강아지·고양이·발자국 모티프; 다크에서는 알파가 있는 동일 마크를 onSurface 색으로 tint.
- 아이콘: 기능 한 가지당 역할 하나, 단일 의미, stroke 스타일(Material Outlined), 기본 24dp, 버튼 터치 영역 최소 48dp, selected/unselected 상태는 텍스트와 시맨틱 동시 전달.

## 파일 및 사용처
- `drawable-nodpi/petworld_brand_mark.png` — 앱 헤더/브랜드.
- `drawable-nodpi/ic_launcher_foreground.png` — Android Adaptive foreground/monochrome.
- `mipmap-mdpi|hdpi|xhdpi|xxhdpi|xxxhdpi/ic_launcher.png` — 이전 Android 버전의 런처 표시.
- `mipmap-anydpi-v26/ic_launcher.xml` — 배경색/전경/단색 적응형 아이콘.
- `ui/icons/PetIcons.kt` — 내비게이션·일상·건강·관리·일반 액션 아이콘.
- `ui/components/PetIcon.kt` — 24dp·테마 색상 기반 공통 렌더러.
- `PetWorldApp.kt` — 헤더 워드마크, 5탭, 기록 준비 중 리스트에 적용.
- `PetIconsTest.kt` — 탭 5개 및 일상 5개 아이콘의 매핑 검사.

## 기능별 아이콘 사전
- 메인 탭(5): Home / Records / Health / Statistics / More.
- 일상(7): Profile / Food / Water / Elimination / Activity / Sleep / Weight.
- 건강(5): Symptoms / Vet / Vaccination / Medication / Prevention.
- 관리(5): Expenses / Household / Album / Report / Observation(AI 선택형).
- 공통 액션(24): Add, Edit, Delete, Search, Filter, Sort, Calendar, Notifications, Share, Export, Import, Settings, Help, Info, Back, Close, Done, Warning, Attachment, Camera, Gallery, Sync, Lock, Logout.
- 추후 기능 구현 시 이 아이콘 사전을 참조하고 앱 곳곳에 다른 도형/색상 스타일이 섞이지 않도록 한다.

## 품질 검증
- 리소스 중복/누락 및 API 26 미만 fallback, Android 13+ monochrome 레이어 구성을 빌드·lint로 검사.
- 라이트/다크 강제 전환 시 마크가 배경과 충분히 대비되는지 실제 화면 캡처 필요.
- 런처 크기 48/72/96/144/192 px에서 얼굴·발바닥 인식 여부 실기기 확인 필요.
- TalkBack은 이모지나 이미지만 전달하지 않으며 텍스트 라벨/시맨틱으로 기능 설명.
- Android CI: `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug`.
- 실기기·태블릿·160% 글꼴 캡처 검수 전에는 디자인 최종 QA가 완료되었다고 표기하지 않는다.
