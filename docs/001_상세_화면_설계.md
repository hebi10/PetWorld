# PetWorld | 001 상세 화면·정보 구조 설계
> 기준일: 2026-11-09 · 상태: 0단계 IA/UX 기준선 v1.0 · 시각 디자인 최종 시안 아님

## 1. 탐색 구조 및 화면 공통 규칙
- **하단 5개 탭:** 홈 / 기록 / 건강 / 통계 / 더보기. 초기 MVP에서는 건강 탭에 체중 중심 화면을 표시하고 후속 단계에서 증상·진료·복약 모듈을 확장한다. 제공하지 않는 기능을 활성 버튼으로 노출하지 않는다.
- **개체 컨텍스트:** 홈·기록·건강·통계 헤더 상단에 선택 동물의 사진+이름+전환 표시. 기록 작성 중 전환은 확인 후 반영한다. ‘전체 반려동물’ 혼합 보기 및 공용 기록은 MVP에서 제공하지 않는다.
- **공통 컴포넌트:** P01 PetSwitcher, P02 QuickRecordSheet, P03 DateRangePicker, P04 NumberWithUnit, P05 StatusPill, P06 RecordCard, P07 EmptyState, P08 ConfirmDialog, P09 SaveFeedback, P10 AttachmentPicker.
- **화면 상태:** 빈 데이터에서는 안내+직접 실행 가능한 CTA, 오류는 원인과 재시도, 저장 중 중복 클릭 방지, 저장 실패는 입력값 보존.
- **내비게이션:** 탭을 바꿔도 petId 유지; 하위 상세에서 Android 뒤로가기는 원래 목록의 필터·스크롤을 복원; 시스템 제스처/키보드/접근성 지원.
- **모바일 레이아웃:** 콘텐츠 여백 약 16dp를 출발 기준으로 하고 폰트 160%에서도 버튼이 접히지 않도록 가변 구성. 디자인 토큰은 이후 확정.
- **태블릿/폴더블:** 홈은 요약과 최근 기록 2열, 기록은 목록+상세, 통계는 그래프+지표의 적응형 2열; 폴더블 중간 펼침/접힘 시 입력 데이터 보존.
- **입력 폼 원칙:** 개체 표시 → 종류·값·단위 → 발생일시 → 메모/사진(선택) → 하단 저장. 유효성 오류는 해당 필드 바로 아래 설명.

## 2. 전체 화면 목록 및 릴리스
### 진입·홈
- **S00 시작/초기 상태 (MVP):** 프로필 유무 로딩, 최초 등록 안내, 복구 진입. 첫 화면에 계정·알림 권한 강제 금지. CTA ‘반려동물 등록’, 보조 ‘백업 복원’.
- **S01 최초 등록 안내 (MVP):** 기록 목적·로컬 보관·동물 등록 정보, 1~2문단 설명, ‘시작하기’. 건너뛰기를 허용하지 않아도 되지만 복구 진입은 가능.
- **S02 프로필 등록·편집 (MVP):** 사진, 이름(필수), 종(필수), 품종, 생일/추정 나이, 성별, 중성화, 주의사항, 활성화할 기록 유형; 오류/저장 중/사진 거부 상태.
- **S03 홈 대시보드 (MVP):** PetSwitcher, 오늘 날짜, 입력 현황 5개(식사·음수·배변·활동·체중), 빠른 기록, 최근 기록 최대 5개, 향후 일정(지원 시). CTA ‘기록 추가’.
- **S04 반려동물 전환 시트 (MVP):** 이름·사진·종 프로필 목록, 현재 선택 체크, 추가 버튼, 보관 프로필 접근. 기록 작성 중에는 미저장 내용 확인.
- **S05 빠른 기록 시트 (MVP):** 식사·음수·배변·활동·체중 아이콘+텍스트, 최근 사용 유형 상단(선택 구현), 탭 후 해당 폼. 선택 중 이름 고정.

### 일상 입력·기록
- **S06 식사 입력 (MVP):** 종류, 제품명, 제공량·단위, 섭취량(선택)·단위, 발생일시, 메모, 저장. 제공량 > 0, 섭취량 ≤ 제공량(동일 단위) 검증.
- **S07 음수 입력 (MVP):** 섭취량 mL/미측정 토글, 발생일시, 메모. 공동 급수기 추정값은 직접 입력만 허용, 자동 분배 금지.
- **S08 배변 입력 (MVP):** 소변/대변, 횟수, 시각, 관찰 상태, 사진·메모. 상태 미선택 가능, 소변/대변 오분류 쉽게 수정 가능.
- **S09 활동 입력 (MVP):** 산책/놀이/수면/기타, 시작일시, 지속시간, 메모. 기간 비정상/겹침은 설명식 경고.
- **S10 체중 입력 (MVP):** 체중 숫자, kg/g 단위, 날짜·시각, 메모. 0/음수는 저장 차단, 지나친 변경은 확인 안내.
- **S11 기록 타임라인 (MVP):** 상단 PetSwitcher, 날짜 이동, 유형 필터, 기록 카드, 추가 FAB/버튼, 빈 결과에서 필터 초기화. 기록마다 발생시각·유형·핵심값.
- **S12 기록 상세·편집 (MVP):** 원본 정보, 작성/수정 시각, 수정·삭제 버튼, 타입별 입력 폼 재사용, 저장 전 확인 및 삭제 취소.
- **S13 날짜·유형 필터 (MVP):** 오늘/7일/30일/직접 선택, 유형 다중 선택, 적용·초기화. 필터 종료 후 복귀 시 선택 유지.

### 건강·통계
- **S14 통계 홈 (MVP):** 개체 고정, 기간 선택, 체중 그래프, 식사 제공·섭취, 음수 합계, 배변 빈도, 활동 시간 요약. 데이터가 적으면 지표 계산 조건 표시.
- **S15 유형별 차트 상세 (MVP):** 그래프·단위·기간·점별 원본 기록 링크, 기록 누락/미측정 범례, 이전 기간 비교(자료 충분 시).
- **S16 반려동물 프로필 상세 (MVP):** 프로필 사진, 기본 정보, 주의사항, 개별 기록 설정, 편집, 보관·삭제(안전 확인).
- **S17 프로필별 홈 구성 (MVP):** 기록 바로가기 표시·순서, 기본 입력 단위/선호 화면, 설정 변경 시 기존 기록 보존.
- **S18 건강 홈 (MVP 체중 / 확장1 건강):** 체중 요약 및 최근 이력(MVP), 증상/진료/복약/예방(해당 기능 구현 이후), 예정 돌봄.
- **S19 증상 일지·입력 (확장1):** 증상 선택/직접 작성, 발생시각·지속·정도 메모, 첨부, 과거 관찰 연결. 병명 추측 금지.
- **S20 병원 방문 목록·상세 (확장1):** 방문일·병원·주요 사유 목록, 방문 기록 생성, 검사·처방 메모와 영수증, 연결된 증상/복약.
- **S21 예방 관리 일정 (확장1):** 접종/검진/구충 탭, 예정일, 완료 기록, 반복 설정, 알림, 미확인 상태.
- **S22 복약 계획 관리 (확장1):** 약 이름·사용자 입력 계획·날짜·회차, 예정/완료/건너뜀·미확인 보기, 편집 이력, 담당자.
- **S23 복약 회차 확인 시트 (확장1):** 선택 동물·약 이름·예정 시각, ‘완료’/‘건너뜀’/‘닫기’, 이미 완료한 경우 재완료 불가 안내.

### 더보기·공유·리포트
- **S24 지출 목록·추가 (확장1):** 월 선택, 분류·개체, 합계, 금액·카테고리·영수증 입력, 가구 공용과 개체별 구분.
- **S25 리포트 조건·미리보기 (확장1):** 동물·시작/종료일·포함항목, 집계 전 미측정 안내, 원시 기록과 차트, PDF 내보내기 전 검토.
- **S26 공동 돌봄 홈 (확장2):** 가구 멤버, 초대/역할, 최근 변경, 동기화/오프라인 배너, 로그아웃 시 로컬 데이터 정책.
- **S27 초대·역할·충돌 처리 (확장2):** 초대 코드/수락/만료/취소, 역할 설명, 기록 충돌 비교/선택, 복약 중복 알림.
- **S28 성장 앨범·사진 상세 (확장3):** 월별/반려동물별 사진, 중요한 사건·메모, 사진 누락·공유 상태, 원본 연결.
- **S29 AI 관찰 요약 (확장3):** 기간·근거 기록 수·관찰 후보·누락·추정 표현, 동의/처리 방식 표시, 진료용 편집 초안.
- **S30 더보기·앱 설정 (MVP):** 프로필 관리, 표시 테마, 백업·복원, 앱 정보·개인정보, 확장 기능은 구현 시 노출.
- **S31 백업·복원 마법사 (MVP):** 내보내기 파일+암호 → 안전한 저장 안내 / 복원 파일선택→검증→미리보기→전체교체 최종확인→결과.
- **S32 알림 설정 (확장1):** 권한 상태, 일정 유형별 켜기/끄기, 잠금화면 내용 가리기, 정확도/OS 제한 안내.
- **S33 예외·확인 시트 (공통):** 저장 실패, 빈 목록, 미측정 안내, 사진 선택 취소, 프로필 삭제·기록 삭제, 네트워크/동기화 충돌.
- **S34 태블릿·폴더블 레이아웃 (공통):** 별도 기능이 아니라 S03/S11/S15/S20/S25 등의 2열/분할 화면 버전과 크기별 내비게이션 규칙.

## 3. 대표 모바일 저충실도 와이어프레임
### W01 — S03 홈 (선택 동물 컨텍스트 고정)
```text
┌──────────────────────────────┐
│ PetWorld         설정        │
│ [사진] 나비 ▾     11월 9일   │
├──────────────────────────────┤
│ 오늘의 기록                  │
│ 식사 2건       음수 180mL    │
│ 배변 1건       활동 20분     │
│ 체중 기록 없음              │
│ [ + 빠른 기록 ]              │
├──────────────────────────────┤
│ 최근 기록             전체 ▸ │
│ 08:20 · 식사 · 제공 40g      │
│ 07:15 · 배변 · 소변          │
├──────────────────────────────┤
│ 홈 | 기록 | 건강 | 통계 | 더보기│
└──────────────────────────────┘
```
- 상단의 기록 없는 항목은 ‘안 했음’이 아닌 ‘기록 없음’. 각 카드 선택 시 해당 항목 필터로 이동.

### W02 — S05 빠른 기록
```text
┌──────────────────────────────┐
│ 나비의 기록 추가         닫기│
├──────────────────────────────┤
│ [식사]         [음수]        │
│ [배변]         [활동]        │
│ [체중]                       │
│                              │
│ 대상: 나비 (변경하려면 닫기) │
└──────────────────────────────┘
```
- 최초 진입은 5개 선택지 고정. 모션/호버 장식 없음. 어느 폼에서도 petId가 자동 변경되지 않음.

### W03 — S06 식사 입력
```text
┌──────────────────────────────┐
│ ‹ 식사 기록             나비 │
├──────────────────────────────┤
│ 식사 종류  [사료 ▾]          │
│ 제품명     [선택 입력]       │
│ 제공량     [  40  ] [g ▾]   │
│ 섭취량     [미측정] [  ]     │
│ 발생 시각  [오늘 08:20 ▾]    │
│ 메모       [               ] │
│                              │
│ [          저장           ]  │
└──────────────────────────────┘
```
- 제공량과 섭취량 구분 필수; 미측정은 숫자 0과 다름. 키보드가 보여도 저장 버튼 도달 가능.

### W04 — S11 기록 목록
```text
┌──────────────────────────────┐
│ 나비 ▾           11월 9일 ▾  │
│ [모두] [식사] [음수] [배변]  │
├──────────────────────────────┤
│ 08:20 사료 제공 40g          │
│       섭취량 미측정      ›   │
│ 07:15 소변 1회           ›   │
│ 06:50 물 120mL           ›   │
│                              │
│                     [+ 추가] │
├──────────────────────────────┤
│ 홈 | 기록 | 건강 | 통계 | 더보기│
└──────────────────────────────┘
```
- 목록에서 스와이프 삭제를 기본 제공하지 않음. 상세에서 삭제 확인.

### W05 — S14 통계 홈
```text
┌──────────────────────────────┐
│ 나비 ▾     [7일] [30일] [선택]│
├──────────────────────────────┤
│ 체중 변화         kg        │
│     ●───────●           ▸   │
│  측정 2회 / 미측정일 별도    │
├──────────────────────────────┤
│ 식사 제공량   300g          │
│ 실제 섭취량   기록 3건      │
│ 음수 기록     합계 900mL    │
│ 배변          소변 4/대변 2 │
│ 활동          120분         │
├──────────────────────────────┤
│ 홈 | 기록 | 건강 | 통계 | 더보기│
└──────────────────────────────┘
```
- 별도 일별 차트에서는 0과 미기록의 시각적 차이를 표기. 그래프 수치 선택 시 원본 기록으로 이동.

## 4. 화면 흐름별 동작
- **첫 실행:** S00 → (신규) S01 → S02 → S03 / (기존 백업) S31 → S03. 권한 안내는 사용 시점에만.
- **기록 추가:** S03 → S05 → S06~S10 → 저장 성공 → S03 또는 직전 화면. 저장 실패 시 입력 폼 유지.
- **기록 수정:** S11 → S12 → 유형별 폼 → 저장→상세 복귀→목록/통계 자동 갱신.
- **동물 전환:** P01 → S04 → 선택 → 현재 탭으로 복귀, 필터는 새 동물에 맞춰 재평가.
- **건강 상담:** S18 → S19/S20/S22 → S25 → 미리보기 → 사용자 확인 → PDF 내보내기 (확장1).
- **돌봄 공유:** S26 → S27 초대 → 수락 → 권한 설정 → 동기화/충돌 표시 (확장2).
- **AI:** S29은 명시적 동의 후 사용, 다른 기능의 기록을 임의로 수정하지 못함.

## 5. 화면별 빈·오류·확인 상태
- 처음 동물 없음: S00 안내, 등록/복원 두 CTA. 이미 생성한 동물 없음은 기록·건강·통계로 진입 전에 차단하고 프로필 생성으로 유도.
- 선택 기간 기록 없음: ‘이 기간에 입력된 기록이 없습니다’ + 해당 유형 기록 CTA. ‘건강 이상 없음’으로 표현 금지.
- 통계 자료 부족: 데이터 개수/기간 표시, 계산 불가 지표는 대시 ‘—’와 이유 안내.
- 입력 오류: 숫자 단위·일시·제공량/섭취량 관계 등 개별 메시지, 초점 이동.
- 저장 실패/용량 부족: 사용자 입력값 그대로 유지, 재시도 버튼, 중복 저장 방지.
- 첨부 취소/권한 거절: 텍스트 기록은 계속 진행.
- 미저장 이탈: ‘계속 작성 / 변경 폐기’ 확인. 기본은 계속 작성.
- 백업 손상/암호 오류: 기존 DB 보존, 오류 원인 구분, 재시도.
- 동기화 오류(확장2): 변경 대기/충돌 상태와 로컬 자료 보존 여부 명시.

## 6. 디자인·접근성 기준
- **Pet Journal:** 사진과 기록 중심의 생활 다이어리, 단색/중성 회색 위주의 정돈된 정보형 UI.
- 라이트: 흰색·중성 회색. 다크: 차콜·검정. 상태별 필요한 경우에만 의미색.
- 그림자·둥근 장식·아이콘 입체감·그라데이션·불필요 애니메이션 없음. 터치·타이포·간격 우선.
- 모든 아이콘에는 텍스트 또는 접근성 라벨. 160% 폰트에서 두 줄 레이블, 고대비, 키보드·스크린리더 이용 지원.
- 숫자·단위·기간·반려동물 이름은 읽기 순서와 보조 설명을 함께 제공.
- 폴더블 포스트처 변경 시 폼 상태와 선택 대상은 유지; 태블릿의 넓은 빈 공간은 분할 패널로 처리.
