PetWorld 개인정보처리방침

시행일: 2026년 11월 9일 · 개발자: 해비

이 방침은 Android 앱 PetWorld(com.haebi.petworld)의 현재 배포 기능에 적용됩니다.

기기 안에서 처리하는 정보

반려동물의 이름·종류·생일 등 프로필, 사용자가 선택한 사진, 식사·건강·활동 등 일상 기록과 앱 설정은 사용자의 기기에 저장됩니다. 앱은 이 정보를 개발자 서버로 전송하지 않습니다.

계정·광고·분석

현재 앱에는 회원가입이나 로그인, 광고, 결제, 사용자 행동 분석 및 오류 수집 SDK가 없습니다. 현재 Android 앱은 인터넷 접근 권한을 요청하지 않습니다.

사진 선택

반려동물 사진은 사용자가 시스템의 사진·파일 선택 화면에서 직접 고릅니다. 선택한 사진은 프로필 표시에 필요한 범위에서 앱의 기기 내 저장소에 보관됩니다.

보관 및 삭제

앱에 저장한 프로필과 기록은 앱의 관리 기능에서 삭제할 수 있습니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 앱 내부 저장 데이터가 삭제됩니다. 현재 앱은 Android 자동 백업을 사용하지 않습니다.

외부 서비스 및 변경

이 방침 페이지를 브라우저에서 열면 페이지 제공 서비스인 GitHub Pages에 일반적인 접속 정보가 전달될 수 있습니다. 앱의 데이터 처리 방식이 변경되면 이 방침을 갱신합니다.
