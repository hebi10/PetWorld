## 1. 적용 기준

초기 001은 2026-11-09 IA/UX **초안 v1.0**이며, 같은 날 작성된 005는 Android 일상 기록의 상세 구현 계약입니다.

기록 관련 기능과 UI가 서로 충돌하는 경우, **현재 MVP 및 배포 대상은 후속 005 구현 명세를 우선**으로 해석합니다. 초기 001에 기재되어 있다는 사실만으로 새 데이터 컬럼이나 화면을 추가하지 않습니다. 이 문서는 *현재 구현 범위*와 *후속 기능 후보*를 구분하는 기준선이며, 후속 기능의 개별 구현을 승인하거나 영구 취소한다는 의미는 아닙니다.

### 결정의 영향

1. S08은 메모와 사진으로 관찰 상태를 기록할 수 있지만, **분류형 상태 선택 기능이 구현된 것으로 표기하지 않습니다**.
2. S13의 '전체 유형'은 기존 단일 유형 선택을 해제하는 옵션입니다. 다중 선택이나 날짜 직접 선택이 가능한 것으로 안내하지 않습니다.
3. S15/S17은 **초기 MVP 기획과 최신 구현의 범위 차이**로 이력에 남깁니다. 기존 UI가 고장 났다는 의미는 아닙니다.
4. Play 스토어 기능 설명, 테스트 스크립트, README에는 현재 구현된 기능만 사실대로 표현해야 합니다. 기능 확장 시 이 기준선을 수정합니다.

## 3. UI-10-F 실제 코드·검증 보강

- `CareRange.ALL`은 **저장된 모든 유효한 기록**을 보여줘야 하므로 오늘 이후 날짜라는 이유만으로 제외하지 않도록 수정합니다. 기존 유효성 검증에서 5분 이내의 미래 시각은 허용하기 때문에 자정 부근에 실제 저장된 기록이 '전체'에서 누락될 가능성이 있었습니다.
- `TODAY / SEVEN / THIRTY`는 기존처럼 오늘을 포함한 당일·7일·30일 구간을 유지합니다.
- 목록의 기간·유형 필터 조건은 `filterCareRecords()`로 추출하고 기존 목록 UI에서 같은 함수 사용. 결과에 대한 JUnit 검증으로 변경 전후 행동을 고정합니다.
- S08 배변 소변/대변·횟수·관찰 메모·사진 파일 식별자 보존 테스트를 추가합니다.
- 현행 Record List 계측 테스트가 기간 변경·유형 1개 선택·'전체 유형' 복귀를 확인합니다.
- Room 엔터티, DB 버전, 암호화 백업·복원 포맷, 사진 복사, 앱 ID, 버전/서명, 아이콘, Play 등록정보는 변경하지 않습니다.

## 4. UI-10-F 완료 기준

1. 현행 MVP와 미래 기능을 구분한 본 문서가 PR에 포함됨.
2. JUnit: 5가지 타입 단일 선택/전체 해제, 오늘·7일·30일·전체의 경계, 자정 직후 유효한 기록의 전체 조회, 배변 관찰 데이터 보존.
3. Android CI 단위/Lint/Debug 성공, 기록 목록 UI와 필터 복귀 계측 성공.
4. 이전 PR #21 최종 QA 상태 검증 및 후속 회귀(화면·백업·Fold)를 확인.
5. 최종 통합 QA/UI-10-G 전까지 Draft PR, `main` 미병합 및 Play 미배포 유지.
