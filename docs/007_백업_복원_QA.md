## 3. 실제 기기 QA 절차

1. 테스트 전 현재 반려동물 데이터를 별도 암호화 백업으로 보관
2. 두 반려동물 생성, 각 프로필 사진 추가, 식사·음수·배변·활동·체중 기록 생성
3. 더보기 → 데이터 관리 → 암호화 백업 생성, 시스템 파일 선택기로 `.petworld` 저장
4. 프로필·기록·테마 변경 뒤 백업 복원 → 암호 입력 → 데이터 교체 확인
5. 프로필 UUID·사진·5종 기록·시각·단위·테마 및 선택 프로필 확인
6. 동일한 파일에 잘못된 암호로 복원 시 데이터 불변 확인
7. 대용량 사진, 저장 권한 취소, 파일 선택 취소 및 여유 저장 공간 부족 테스트
8. 복원 중 `am force-stop` 등으로 프로세스를 종료하고 앱 재실행 → 원상복귀 및 저널 삭제 확인
9. 다크/라이트, 세로/가로, 폴더블/태블릿, 글꼴 160%와 TalkBack 사용성 확인

## 4. 출시 금지 조건

- 실제 기기 검증이 수행되지 않은 상태를 기기 QA 통과로 표시하지 않음
- 새 계측 workflow가 실패하거나 도중 중단되면 로그 분석 및 수정 후 재검증
- 데이터 불변성, 복구 저널, 사진 정확도에 하나라도 문제가 있으면 Draft PR 유지
- 수동 테스트에서 사용자 데이터 훼손을 방지하기 위해 테스트 데이터 전용 환경에서 먼저 진행
