# PetWorld

> 반려동물마다 다른 생활 패턴과 건강 기록을 한곳에서 관리하는 Android 반려동물 케어 앱.

**프로젝트 상태: 기획 단계 (Planning)**  
**플랫폼: Android 우선**  
**개발 방향: Kotlin + Jetpack Compose 기반 네이티브 앱 제안**  
이 문서는 제품 요구사항 및 개발 로드맵 초안입니다. 아래 기능은 구현 완료를 의미하지 않습니다.

## 1. 프로젝트 개요

PetWorld는 **다중 반려동물 프로필 · 식사와 음수량 · 배변과 활동 · 체중과 건강 · 진료와 복약 · 지출 · 공동 돌봄 · 성장 기록**을 연결하는 생활 관리 애플리케이션입니다.

기록 입력 자체보다 **반려동물의 일상 변화를 쉽게 확인하고, 돌봄 담당자 사이에 빠짐없이 공유하고, 진료 시 유용한 경과 기록을 제공**하는 데 집중합니다. 고양이·강아지를 우선 고려하되 동물 종별로 필요한 기록 항목을 달리 설정할 수 있도록 설계합니다.

### 주요 대상

- 한 마리 또는 여러 마리의 반려동물을 함께 돌보는 보호자
- 급여·복약·배변·체중을 꾸준히 기록해야 하는 사용자
- 가족·돌봄 담당자와 생활 기록을 공유하려는 사용자
- 병원 방문 시 지난 증상·식사·체중 변화를 정리하고 싶은 사용자

### 핵심 가치

1. **반려동물별 기록 분리**: 여러 마리의 생활 정보를 혼동하지 않도록 프로필과 기록을 연결
2. **빠른 일상 입력**: 홈에서 1~2번의 조작으로 주요 돌봄 기록
3. **맥락 있는 변화 확인**: 체중, 식사, 음수, 배변, 활동 등을 같은 기간에 비교
4. **안전한 공동 돌봄**: 담당자별 기록과 완료 여부를 명확하게 표시
5. **관찰 보조, 진단 대체 금지**: 데이터 요약은 제공하되 질병을 단정하지 않음

## 2. 주요 기능 기획

| 영역 | 핵심 기능 | 상세 요구사항 |
| --- | --- | --- |
| 반려동물 프로필 | 다중 프로필 | 이름, 사진, 종, 품종, 생일·추정 나이, 성별, 중성화 여부, 주의사항 |
| 홈 대시보드 | 오늘의 돌봄 | 반려동물 전환, 최근 기록, 예정된 복약·진료, 빠른 입력, 누락 항목 |
| 식사 기록 | 급여·사료 관리 | 사료·습식·간식, 급여량, 섭취량, 시간, 급여자, 제품별 메모 |
| 음수량 | 음수 기록 | 물 섭취량 수동 입력, 기간별 추이, 여러 반려동물 구분 |
| 배변 기록 | 소변·대변 관찰 | 시간, 횟수, 상태, 특이 사항, 사진·메모(선택) |
| 생활 활동 | 산책·놀이·수면 | 시간·지속시간·활동 유형, 종별 선택 항목 |
| 체중·신체 | 변화 추적 | 체중 이력, 추이 그래프, 측정 날짜, 메모, 데이터 수정·보정 |
| 건강 일지 | 증상 관찰 | 구토, 설사, 식욕 변화 등 사용자 정의 증상, 심각도 메모, 사진 |
| 병원 기록 | 진료·검사 이력 | 병원, 방문 이유, 진료 내용, 검사 결과, 처방, 영수증 첨부 |
| 예방 관리 | 접종·검진 일정 | 예방접종, 정기 검진, 구충 등 예정일·완료 이력, 알림 |
| 복약 관리 | 약 복용 기록 | 약 이름, 투약 계획, 복용 체크, 누락·변경 기록, 복용 담당자 |
| 가계부 | 반려동물 지출 | 사료·병원·용품·미용 등 분류, 반려동물별 비용, 월별 통계 |
| 공동 돌봄 | 가족 공유 | 보호자/돌봄자 권한, 담당자, 기록 변경 이력, 인계 메모 |
| 성장 기록 | 사진·다이어리 | 월별 사진, 중요한 사건, 변화 타임라인, 앨범 |
| 리포트 | 기간별 기록 요약 | 체중·급여·증상·복약·진료 흐름 및 병원용 공유/내보내기 |
| AI 관찰 보조(선택) | 패턴 변화 요약 | 최근 기간과 평소 기록 비교, 누락·이상 변화 후보 설명, 진료용 요약 초안 |

### 종별 설정

- 공통: 식사, 음수, 체중, 복약, 진료, 지출, 앨범
- 고양이 중심: 화장실 기록, 실내 놀이, 구토·헤어볼 메모 등 선택 항목
- 강아지 중심: 산책, 배변, 야외 활동 등 선택 항목
- 특정 기록을 모든 반려동물에게 강제하지 않고 프로필별로 표시 항목을 설정

### 안전·정확성 원칙

- 사용자가 기록한 수치를 기반으로 추세를 보여주며 **자동 측정된 임상 데이터처럼 표현하지 않습니다.**
- AI는 관찰 내역을 요약하고 비교할 수 있지만 **질병 진단, 처방, 약물 용량 결정은 제공하지 않습니다.**
- 증상이 심하거나 응급 상황이 의심되면 앱의 추정보다 수의사 진료를 우선하도록 안내합니다.
- 체중 변화·식사량 분석은 기록 누락과 측정 오차를 함께 표시합니다.
- 공동 돌봄 기록은 입력자·시간·수정 이력을 남기고 중복 투약을 피하도록 완료 상태를 명확히 합니다.

## 3. 핵심 사용자 흐름

### 처음 사용

1. 반려동물 프로필 생성 → 종·기본 정보·사진 등록
2. 기록할 항목 선택 → 알림 및 목표 표시 설정
3. 여러 마리일 경우 추가 프로필 생성
4. 선택적으로 가족·돌봄 담당자 초대

### 매일 사용

1. 홈에서 반려동물 선택 → 오늘의 급여·음수·배변·활동 현황 확인
2. 빠른 기록 버튼 → 종류·양·시간 입력
3. 복약·진료 일정 확인 → 진행 후 완료 처리
4. 누적된 기록을 일·주·월 단위로 확인

### 건강 확인 및 병원 방문

1. 체중과 생활 변화 그래프 확인
2. 증상 기록과 사진·진료 이력 연결
3. 선택 기간을 지정하여 일지·리포트 생성
4. 보호자가 검토한 결과를 병원 상담 자료로 제시

## 6. 기술 및 아키텍처 제안

아래 구성은 **확정된 구현 결과가 아닌 개발 검토안**입니다.

| 영역 | 기술 후보 | 목적 |
| --- | --- | --- |
| UI | Kotlin, Jetpack Compose, Material 3 | Android 네이티브·반응형 UI |
| 앱 구조 | MVVM, 단방향 상태 흐름, Repository 계층 | 입력·집계·화면 상태 분리 |
| 로컬 저장 | Room, DataStore | 개인 기록·설정의 오프라인 보존 |
| 비동기·알림 | Coroutines, Flow, WorkManager, Android 알림 API | 리포트 집계·예정 알림 |
| 첨부 | Android Photo Picker / 시스템 파일 선택기 | 사진·진료 자료 선택 |
| 공동 돌봄 | Firebase Auth + Firestore 등 검토 | 계정·가족 권한·동기화 |
| 파일 동기화 | 선택적 클라우드 스토리지 | 사진·진료 첨부 백업 |
| AI 분석 | 선택형 모듈, 온디바이스/서버 비교 | 관찰 기록 요약 및 패턴 변화 설명 |
| 배포 | GitHub Actions + Google Play 테스트 트랙 | 빌드·검증·테스트 배포 |

초기 버전은 **로그인 없이 단일 기기에서 여러 반려동물 기록**을 관리하는 로컬 중심 MVP로 시작하고, 이후 동기화와 공동 돌봄을 추가합니다.

## 7. UI/UX 방향

- 콘셉트: **Pet Journal** — 반려동물 사진과 기록이 중심인 차분한 생활 다이어리
- 라이트/다크/시스템 테마, 중성 색상과 명확한 상태 색상
- 과한 그림자·장식·캐릭터 UI보다 기록 가독성과 빠른 입력을 우선
- 다중 프로필 전환을 고정된 위치에 제공하고, 입력 대상 반려동물을 명확히 표시
- 수치·단위·날짜 및 그래프 기준 범위를 눈에 띄게 표시
- 빈 데이터, 입력 오류, 알림 거부, 동기화 실패 등 예외 상태를 별도 설계
- 작은 화면·태블릿·폴더블, 글꼴 확대, 접근성 검증

## 8. 개인정보 및 보안

- 기본 사용에 계정을 강제하지 않고 필요한 데이터만 저장
- 진료 기록·사진·가족 정보는 민감할 수 있으므로 권한을 최소화
- 공동 그룹에서는 소유자·구성원 권한과 초대 해제·그룹 탈퇴·기록 내보내기 지원
- 알림 내용에 의료·개인 정보가 불필요하게 노출되지 않도록 설정 제공
- 클라우드 저장·AI 분석은 별도 동의와 서비스별 처리 방식 안내
- 사용자가 데이터를 수정·삭제·백업·내보낼 수 있는 구조 설계
- API 인증 정보와 비밀키는 저장소·앱에 평문으로 포함하지 않음

## 9. 개발 로드맵

| 단계 | 범위 | 완료 기준 |
| --- | --- | --- |
| 0 — 제품 명세 | 기록 유형·단위·예외 정의, 화면 흐름, 데이터 모델 | MVP 시나리오·경계 조건 확정 |
| 1 — 앱 기반 | Compose 프로젝트, 디자인 시스템, 로컬 DB, 테스트 | 탐색·저장·복구 정상 |
| 2 — 일상 기록 MVP | 다중 프로필, 식사·음수·배변·활동·체중 CRUD | 각 동물의 기록이 분리되어 정상 보존 |
| 3 — 건강·알림 | 진료·증상·복약·접종, 일정과 알림 | 기록·리마인더·완료 상태 일치 |
| 4 — 통계·리포트 | 그래프, 기간별 비교, PDF/파일 내보내기 | 입력 변경 시 분석 결과 정확 |
| 5 — 공동 돌봄 | 인증, 가족 초대, 권한, 동기화·변경 이력 | 여러 기기의 변경·중복 기록 처리 검증 |
| 6 — 고급 기능 | 성장 앨범, 사진 정리, AI 관찰 요약 | 사실·추정 구분, 개인정보·비용 검증 |
| 7 — 출시 준비 | 접근성, 안정성, Android 실기기 QA, Play 테스트 | 핵심 시나리오 회귀 테스트 통과 |
